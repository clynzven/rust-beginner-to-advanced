# Lesson 21: Project: A CLI Task Manager

*Part 4 · Projects* · Video 21 of 24 in the [Rust: Beginner to Advanced playlist](https://www.youtube.com/@ClynzVen/playlists)

Build a real command-line tool with clap, serde and anyhow, with subcommands, a JSON file store and tests.

## Run it

`cargo run -- --help`, then for example `cargo run -- add Buy milk -p 3`, `cargo run -- list` and `cargo run -- done 1`. Tasks are saved in `tasks.json`.
